Prefill vs Decode：同一引擎，两个阶段

2026-10-20 · README · Q&A

Prefill 与 Decode 曲线是同一 DeepInfer 引擎的两个阶段——不是两个产品。跨机器的 PD 分离属于生产服务胶水，完整方案尚未开源。

同一引擎，两个阶段

Decode输出吞吐 vs 每用户速度64× SM100 · 单一 scale-up 域
