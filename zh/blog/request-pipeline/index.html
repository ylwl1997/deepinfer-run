一次请求如何跑完：生产系统 vs 开源 DeepInfer

2026-10-20 · inference_deployment_qa.md

下列生产数字来自 DeepSeek 公开的推理部署 Q&A / 解读文章，描述的是生产推理系统，不是单独安装开源 DeepInfer 的结果。

架构总览

一次请求如何跑完（概念）

步骤组件发生什么开源？
1API / recipeMessages · Chat Completions · Responses → Conversation → tokensrecipe 为独立 MIT 仓库
2入口 / 缓存匹配路由前做前缀 / KV 命中长度KV 存储未开源
3Prefill 引擎计算未缓存后缀；写入 KV引擎有；服务胶水无
4Decode 引擎自回归出 token；Wide-EP MoE引擎有；LB/分离无
5采样 / DSpark草稿 + 置信度调度校验README 有开关
6recipe 解析token 流 → 协议事件（推理 / 工具 / 正文）recipe 有

生产快照（必须标注归属）

指标公开数值标注
集群 tokens/天约 155 万亿生产系统
低谷收入约 38 美元 / GPU·小时生产系统
平均输入 · 缓存命中约 77K · 约 96%生产系统

高效单元约 64P + 64D · P:D ≈ 1:1生产 / Q&A

开源缺口提示

  • 开源 DeepInfer：离线引擎 + 算子 + EP/DP/CP 示例
  • 未包含：KV cache 系统、完整 PD 分离服务、DP 负载均衡
  • 无官方 Docker 镜像 — 社区 Dockerfile 仅为示例
  • 今日硬件：SM100（CUDA 13）· 昇腾 950（CANN 9.2）
