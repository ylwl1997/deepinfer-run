硬件门槛：SM100、Ascend 950，以及谁该跳过

2026-10-20 · 来源：DeepInfer README

Sponsored slot (inactive)

开源 README 对加速器写得很清楚。本文把它收成「先过门槛，再跑 ./build.sh」的决策表。

支持平台

硬件软件环境变量
NVIDIA SM100 GPUCUDA 13 · GCC ≥ 13 · Python 3.12 · LinuxDEEPINFER_ACCELERATOR=nvidia
华为 Ascend 950 NPUCANN 9.2 · GCC ≥ 13 · Python 3.12 · LinuxDEEPINFER_ACCELERATOR=ascend

「支持」不等于开箱即用的在线 API

完整推理服务仍需（开源版本未包含）：

  • KV cache 系统
  • VE / Prefill / Decode 分离（引擎功能大多已有；完整服务未发布）
  • 面向 prefill 与 decode 的 DP 副本负载均衡

决策清单

  • 确认库存是 SM100 或 Ascend 950
  • 确认 CUDA 13 或 CANN 9.2 与卡匹配
  • 默认按离线 V4.1-Flash 规划，除非你自带服务胶水
  • 若要智能体 → 停，打开 dshbase.com
  • 若只要协议/提示词 → deepseek-recipe

上游基准说明

Prefill：4× SM100。Decode：64× SM100。各自在一个 scale-up 域内。复现用 examples/sweep/run_sweep.sh——不要把第三方 tok/s 写进方案书。
