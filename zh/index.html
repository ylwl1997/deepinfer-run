谁该跳过，谁适合安装

详见 硬件门槛。

请跳过，若你…

  • 只需官方托管 API
  • 要的是智能体框架 → DSH
  • 只需协议层 → recipe
  • 没有 SM100 或 Ascend 950
  • 需要完整在线服务（KV cache、PD 分离、DP 负载均衡——本版本未包含）

适合安装，若你…

  • 要离线跑 DeepSeek-V4.1-Flash
  • 具备 Linux、Python 3.12、GCC ≥ 13，以及 CUDA 13 或 CANN 9.2
  • 能按官方 README 完成构建
