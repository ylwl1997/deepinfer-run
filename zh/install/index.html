安装 DeepSeek DeepInfer

步骤对齐 官方 README。硬件与版本号不自行杜撰。

官方仓库 硬件门槛 默认权重
Sponsored slot (inactive)
硬件门槛。开源版本支持的加速器仅有 NVIDIA SM100 与 华为 Ascend 950。完整表格见 硬件页。

1. 前置条件

  • Linux
  • GCC ≥ 13.0
  • Python 3.12（建议干净虚拟环境）
  • CUDA 13 — 仅 NVIDIA
  • CANN 9.2 — 仅 Ascend

2. 选择加速器

平台环境变量工具链
NVIDIA SM100DEEPINFER_ACCELERATOR=nvidiaCUDA 13
华为 Ascend 950DEEPINFER_ACCELERATOR=ascendCANN 9.2

3. 从源码构建

export DEEPINFER_ACCELERATOR=nvidia
./build.sh
# Ascend：export DEEPINFER_ACCELERATOR=ascend

4. 离线推理冒烟

export DEEPINFER_HF_MODEL_DIR=/path/to/DeepSeek-V4.1-Flash-1017
python examples/offline_inference.py

默认权重：deepseek-ai/DeepSeek-V4.1-Flash-1017。

5. 本版本未包含

  • KV cache 系统
  • 完整的 VE / Prefill / Decode 分离服务
  • 面向 prefill 与 decode 的 DP 副本负载均衡
许可证：Apache 2.0。上游致谢中说明主要基于 vLLM，并参考 SGLang 与 TensorRT-LLM。
