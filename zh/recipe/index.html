deepseek-recipe

协议与提示词——不是推理引擎。推理、工具与 HTTP 由调用方提供。

Sponsored slot (inactive)
组件职责
deepseek-recipe请求 → 提示词 / token；输出 → 协议响应
DeepInfer在加速器上执行推理
你的服务HTTP、鉴权、工具、服务胶水

Python

python3 -m pip install deepseek-recipe
from deepseek_recipe import ChatCompletionRequest, ConversionOptions, DeepseekV41Encoding
request = ChatCompletionRequest({"model":"DeepSeek-V4.1-Flash","messages":[{"role":"user","content":"你好"}]})
converted = request.convert(ConversionOptions())
print(DeepseekV41Encoding().render_conversation(converted.conversation).prompt)
