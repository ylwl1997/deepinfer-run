开源不包含什么

  • 开箱即用的多租户在线 API + 长保留 KV
  • 生产级 Prefill/Decode 分离服务（同一引擎内存在两阶段；完整胶水在树外）
  • prefill / decode 副本的 DP 负载均衡器
  • 智能体运行时 — 见 DeepSeek Harness · dshbase.com
  • 仅协议转换 — 见 deepseek-recipe（不推理）
Prefill ≠ 独立产品。Prefill 与 Decode 是同一 DeepInfer 引擎的两个阶段。4× SM100（prefill）与 64× SM100（decode）是基准拓扑，不是两次安装。见 Prefill vs Decode。
