社区 RFC — 今日尚不支持

仅为草稿 RFC。不要声称 910C、SM90 或 H20 已支持。实现尚未合入；请跟踪 PR。

服务缺口（开源发行）

README 列出完整推理服务仍缺的部分——未包含在本次开源中：

缺失为何重要
KV cache 系统在线多轮 / 高 QPS 复用
VE / Prefill / Decode 分离引擎侧多数能力已有；完整服务胶水未开源
DP 负载均衡prefill 与 decode 副本均衡

跳过清单

  • 既无 SM100 也无 Ascend 950 → 跳过安装；关注 RFC 或用托管 API
  • 托管 Chat Completions 已够用 → 跳过自建
  • 需要智能体 → DeepSeek Harness · dshbase.com
  • 只需协议 / 提示词 → deepseek-recipe
  • 今日就要完整在线 KV + PD 服务 → OSS 未交付该栈
