DeepInfer 硬件：SM100、昇腾 950、CUDA 13、CANN 9.2

依据 官方 README。加速器不在列表中就不要强行编译。

支持硬件：NVIDIA SM100 与华为昇腾 950

加速器厂商工具链环境变量
SM100 GPUNVIDIACUDA 13DEEPINFER_ACCELERATOR=nvidia
Ascend 950 NPU华为CANN 9.2DEEPINFER_ACCELERATOR=ascend

软件前置

  • Linux
  • GCC ≥ 13.0
  • Python 3.12
  • CUDA 13 或 CANN 9.2

模型

DeepSeek-V4.1-Flash · 默认权重示例 deepseek-ai/DeepSeek-V4.1-Flash-1017。

上游基准

Prefill：4× SM100。Decode：64× SM100。各自在一个 scale-up 域内。复现见 examples/sweep/run_sweep.sh。

服务缺口：KV cache、Prefill/Decode 分离、负载均衡

缺失为何重要
KV cache 系统在线多轮 / 高 QPS
VE / Prefill / Decode 分离完整服务胶水未开源
DP 负载均衡prefill + decode 副本均衡

跳过条件

  • 既无 SM100 也无 Ascend 950
  • 托管 API 已够用
  • 需要智能体 → DSH
  • 只需协议 → recipe
