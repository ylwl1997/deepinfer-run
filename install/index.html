Install DeepSeek DeepInfer

Checklist mirrored from the official DeepInfer README. We do not invent MIPS, pricing, or token throughput — follow upstream for numbers and images.

Official repo README.md Default checkpoint (HF)
Sponsored slot (inactive)
Hardware gate. Supported accelerators in the open-source release: NVIDIA SM100 GPUs and Huawei Ascend 950 NPUs only. If you don’t have them, use the official API or another stack — don’t force-build.

1. Prerequisites

  • Linux
  • GCC ≥ 13.0
  • Python 3.12 (empty/dedicated environment recommended)
  • CUDA 13 — NVIDIA only
  • CANN 9.2 — Ascend only

2. Choose accelerator

PlatformEnv varToolchain
NVIDIA SM100DEEPINFER_ACCELERATOR=nvidiaCUDA 13
Huawei Ascend 950DEEPINFER_ACCELERATOR=ascendCANN 9.2

3. Build from source

Create and activate an empty Python 3.12 environment first. Keep the accelerator env var exported wherever you run DeepInfer.

# NVIDIA (default path in README)
export DEEPINFER_ACCELERATOR=nvidia
./build.sh

# Ascend — use ascend instead
# export DEEPINFER_ACCELERATOR=ascend
# ./build.sh

4. Offline inference smoke check

Default checkpoint: deepseek-ai/DeepSeek-V4.1-Flash-1017 (downloaded into the Hugging Face cache on first run). For a local copy:

export DEEPINFER_HF_MODEL_DIR=/path/to/DeepSeek-V4.1-Flash-1017
python examples/offline_inference.py

See upstream examples/ for details.

5. Features available after build (from README)

  • Optimized kernels (FlashMLA, DeepGEMM, DeepEP, TileKernels, DeepSelect, TileLang ops)
  • Parallelism: Attention DP / balanced CP, MoE EP + EPLB
  • DSpark + confidence-scheduled verification
  • SWA bounded replay
  • Asynchronous scheduling (default)
  • Batch-invariant inference & deterministic sampling (NVIDIA flags)
  • Structured outputs (regex / JSON schema / EBNF)

6. Not included in this release

Required for a complete inference service — not in the open-source release:
  • A KV cache system
  • VE / Prefill / Decode disaggregation (most engine functionality is implemented; full service glue is not)
  • Load balancing across data-parallel replicas for both prefill and decode

7. Performance notes

Official README shows Prefill/Decode Pareto charts measured on 4 SM100 GPUs for prefill and 64 for decode (each within one scale-up domain). Reproduce via examples/sweep/run_sweep.sh. Do not treat third-party blogs as source of truth for numbers.
