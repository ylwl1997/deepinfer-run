Install DeepSeek DeepInfer

Checklist mirrored from the official README. Hardware facts only — no invented throughput or pricing.

Official repo Hardware gate Default checkpoint
Sponsored slot (inactive)
Hardware gate. Supported accelerators: NVIDIA SM100 and Huawei Ascend 950 only. Full table on the hardware page.

1. Prerequisites

  • Linux
  • GCC ≥ 13.0
  • Python 3.12 (empty environment recommended)
  • CUDA 13 — NVIDIA only
  • CANN 9.2 — Ascend only

2. Choose accelerator

PlatformEnv varToolchain
NVIDIA SM100DEEPINFER_ACCELERATOR=nvidiaCUDA 13
Huawei Ascend 950DEEPINFER_ACCELERATOR=ascendCANN 9.2

3. Build from source

export DEEPINFER_ACCELERATOR=nvidia
./build.sh
# Ascend: export DEEPINFER_ACCELERATOR=ascend

4. Offline smoke check

export DEEPINFER_HF_MODEL_DIR=/path/to/DeepSeek-V4.1-Flash-1017
python examples/offline_inference.py

Default checkpoint: deepseek-ai/DeepSeek-V4.1-Flash-1017.

5. Not included in this release

  • KV cache system
  • Full VE / Prefill / Decode disaggregation service
  • Load balancing across DP replicas for prefill and decode
