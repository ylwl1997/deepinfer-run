deepseek-recipe ≠ DeepInfer engine

Protocols and prompts — not inference. You provide the backend, tools, and HTTP.

PieceRole
deepseek-recipeRequest → prompt / tokens; output → protocol responses
DeepInferModel inference on accelerators
Your serviceHTTP, auth, tools, serving glue

Python

python3 -m pip install deepseek-recipe
from deepseek_recipe import ChatCompletionRequest, ConversionOptions, DeepseekV41Encoding
request = ChatCompletionRequest({"model":"DeepSeek-V4.1-Flash","messages":[{"role":"user","content":"Hello"}]})
converted = request.convert(ConversionOptions())
print(DeepseekV41Encoding().render_conversation(converted.conversation).prompt)

Rust

cargo add deepseek-recipe@0.2 deepseek-recipe-encoding@0.2 serde_json@1
