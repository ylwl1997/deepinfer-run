DeepSeek DeepInfer vs vLLM / SGLang / official API

DeepInfer was originally built primarily on vLLM, with additional inspiration from SGLang and TensorRT-LLM (per upstream acknowledgments). This page is about fit, not marketing scores.

Included in DeepInfer open-source release

  • Offline inference path for DeepSeek-V4.1-Flash
  • Optimized kernels & model/sampler runtime
  • Attention DP / balanced CP; MoE EP + EPLB
  • DSpark & confidence-scheduled verification
  • SWA bounded replay; async scheduling
  • Batch-invariant / deterministic sampling flags (NVIDIA)
  • Structured outputs via SamplingParams
  • SM100 + Ascend 950 support as documented

Not included (explicit upstream gaps)

  • KV cache system for full online serving
  • Complete VE / Prefill / Decode disaggregation service
  • Load balancing across DP replicas for prefill and decode
  • Generic “any GPU” support beyond documented platforms
  • Agent orchestration (that’s DeepSeek Harness / DSH)
  • Protocol conversion / tokenizer facade (that’s deepseek-recipe)
Prefill ≠ product. Prefill and Decode charts in the README are two phases of the same DeepInfer engine. See FAQ.

When to stay on the official API

If you need multi-tenant serving, billing, and no accelerator ops — use DeepSeek’s hosted API. Pair clients with deepseek-recipe if you need protocol conversion locally.

When vLLM / SGLang still make sense

Multi-model fleets, accelerators DeepInfer doesn’t list, or an existing vLLM/SGLang production footprint. DeepInfer’s value is DeepSeek’s production path for V4.1-Flash on supported hardware — not being a universal engine.
