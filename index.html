Three layers — don’t mix them up

DeepInfer, deepseek-recipe, and DeepSeek Harness (DSH) solve different problems. Prefill and Decode are phases of the same engine.

Primary · Engine

DeepInfer

Production inference framework for DeepSeek models. Open-source release: offline inference for DeepSeek-V4.1-Flash.

  • Optimized kernels, DP/CP/EP parallelism
  • Hardware: NVIDIA SM100 · Huawei Ascend 950
  • Apache 2.0

github.com/deepseek-ai/DeepInfer

Secondary · Protocols

deepseek-recipe

Rust + Python libraries for request conversion, prompt rendering, tokenization, and response parsing. Does not run inference.

  • Chat Completions / Responses / Messages
  • V4 / V4.1 prompt encoding

Who should not install DeepInfer

Save a weekend — skip the build if any of these match.

Skip if you…

  • Only need Chat Completions via the official DeepSeek API
  • Want an agent / coding harness → use DeepSeek Harness
  • Need protocol conversion only → use deepseek-recipe
  • Don’t have NVIDIA SM100 or Huawei Ascend 950 hardware
  • Need a full online serving stack with KV cache + Prefill/Decode disaggregation (not in this release)

Install if you…

  • Run offline DeepSeek-V4.1-Flash inference
  • Have supported accelerators and Linux + Python 3.12
  • Want DeepSeek’s production kernels (FlashMLA, DeepGEMM, DeepEP, …)
  • Can follow the official README build — this site only mirrors checklists
