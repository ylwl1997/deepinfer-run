Who should skip — and who should install

See also the hardware gate.

Skip if you…

  • Only need the hosted DeepSeek API
  • Want an agent harness → DSH
  • Need protocols only → recipe
  • Don’t have SM100 or Ascend 950
  • Need full online serving (KV cache, PD disaggregation, DP LB — not in this release)

Install if you…

  • Run offline DeepSeek-V4.1-Flash
  • Have Linux, Python 3.12, GCC ≥ 13, CUDA 13 or CANN 9.2
  • Can follow the official README build
