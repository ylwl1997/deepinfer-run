DeepInfer hardware: SM100, Ascend 950, CUDA 13, CANN 9.2

From the official README. If your accelerators aren’t listed, don’t force a build.

Supported hardware: NVIDIA SM100 & Huawei Ascend 950

AcceleratorVendorToolchainEnv
SM100 GPUsNVIDIACUDA 13DEEPINFER_ACCELERATOR=nvidia
Ascend 950 NPUsHuaweiCANN 9.2DEEPINFER_ACCELERATOR=ascend

Software prerequisites

  • Linux
  • GCC ≥ 13.0
  • Python 3.12
  • CUDA 13 or CANN 9.2

Model

DeepSeek-V4.1-Flash · default checkpoint example deepseek-ai/DeepSeek-V4.1-Flash-1017.

Upstream benchmark note

Prefill: 4× SM100. Decode: 64× SM100. Each within one scale-up domain. Reproduce via examples/sweep/run_sweep.sh.

Serving gaps: KV cache, Prefill/Decode disaggregation, load balancing

MissingWhy it matters
KV cache systemOnline multi-turn / high-QPS
VE / Prefill / Decode disaggregationFull service glue not released
DP load balancingReplica balancing for prefill + decode

Skip conditions

  • No SM100 and no Ascend 950
  • Hosted API is enough
  • Need agents → DSH
  • Need protocols only → recipe
