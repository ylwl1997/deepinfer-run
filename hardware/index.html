Software prerequisites

  • Linux
  • GCC ≥ 13.0
  • Python 3.12 (empty env before ./build.sh)
  • CUDA 13 on NVIDIA · CANN 9.2 on Ascend

Supported model in this release

DeepSeek-V4.1-Flash. Default checkpoint example: deepseek-ai/DeepSeek-V4.1-Flash-1017.

Benchmark hardware (upstream)

README Prefill/Decode charts: measured on 4 SM100 GPUs for prefill and 64 for decode, each within one scale-up domain. Reproduce with examples/sweep/run_sweep.sh. We do not invent other MIPS or $/tok figures.

Not included — complete serving still needs

Missing pieceWhy it matters
KV cache systemOnline multi-turn / high-QPS serving usually depends on it
VE / Prefill / Decode disaggregationMost engine functionality exists; full service glue is not in the release
DP load balancing (prefill + decode)Replica-level balancing across data-parallel workers

Skip conditions

  • No SM100 and no Ascend 950
  • You only need hosted Chat Completions
  • You need an agent runtime → DeepSeek Harness
  • You only need protocol conversion → deepseek-recipe
