Community RFCs — unsupported today

Draft RFCs only. Do not claim 910C, SM90, or H20 are supported. Implementation has not landed; track the PRs.
RFCTargetScope / blockers (from PR text)Link
#46 Ascend 910C / A3 Offline-first single-server; V4.1-Flash W8A8 on CANN 9.1; online serving as a later phase. Documented today remains 950 + CANN 9.2. PR #46
#47 SM90 · 4× H20-3E (141 GB) Native FP4 checkpoint capacity ~499 GB of 564 GB; needs dequant-fused FP8 grouped GEMM (no FP4 tensor core on SM90); Hopper attention — FlashMLA dropped Hopper on 2026.09.30. PR #47

Skip checklist

  • No SM100 and no Ascend 950 → skip install; watch RFCs or use hosted API
  • Hosted Chat Completions is enough → skip self-host
  • Need agents → DeepSeek Harness · dshbase.com
  • Need protocols / prompts only → deepseek-recipe
  • Need full online KV + PD service today → OSS does not ship that stack
