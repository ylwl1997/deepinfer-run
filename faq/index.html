DeepSeek DeepInfer FAQ

Short answers with pointers to official sources. This site is independent and not affiliated with DeepSeek.

Is this deepinfer.org (medical)?

No. We deliberately title pages with «DeepSeek DeepInfer» to avoid collision with unrelated medical sites. Canonical: https://deepinfer.run.

Is deepinfer.run affiliated with DeepSeek?

No. Independent guide. Official code lives at GitHub deepseek-ai/DeepInfer and deepseek-ai/deepseek-recipe.

DeepInfer vs deepseek-recipe vs DeepSeek Harness?

  • DeepInfer — production inference engine (offline V4.1-Flash in this release).
  • deepseek-recipe — protocols / prompts / tokenization; does not infer.
  • DeepSeek Harness (DSH) — agent runtime. Guide: dshbase.com. Background for DSH readers: EN · ZH.

Is Prefill a second product?

No. Prefill and Decode are two phases of the same DeepInfer engine. Upstream shows separate Pareto charts because the workloads differ — not because they are separate downloads.

What does “offline inference” mean here?

The open-source release focuses on running inference without DeepSeek’s full production serving shell. A complete online service still needs components called out as not included (KV cache system, full Prefill/Decode disaggregation service, DP load balancing).

Which hardware?

Per official README: NVIDIA SM100 and Huawei Ascend 950. Prerequisites include CUDA 13 (NVIDIA) or CANN 9.2 (Ascend), GCC ≥ 13, Python 3.12, Linux.

Which model?

Supported model listed upstream: DeepSeek-V4.1-Flash. Default checkpoint example: deepseek-ai/DeepSeek-V4.1-Flash-1017 on Hugging Face.

Licenses?

  • deepseek-recipe — MIT License

Where should DSH users start?

Keep using dshbase.com for the harness. Read DeepInfer open source for DSH readers if you care how the inference engine relates to agents — then come back here for engine/recipe install framing.
