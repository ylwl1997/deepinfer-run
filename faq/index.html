DeepInfer vs deepseek-recipe vs DSH?

  • DeepInfer — inference engine (offline V4.1-Flash in this release).
  • deepseek-recipe — protocols; does not infer.
  • DeepSeek Harness — agent runtime · dshbase.com · note for DSH readers.

Is Prefill a second product?

No. Prefill and Decode are two phases of the same DeepInfer engine.

What does “offline” cover?

Core inference without DeepSeek’s full production serving shell. Still missing for complete online service: KV cache, full PD disaggregation service, DP load balancing.

Which hardware / model?

SM100 and Ascend 950. Model: DeepSeek-V4.1-Flash. Defaults and toolchains on the hardware and install pages.

Name collision with medical deepinfer.org?

Unrelated site. We use «DeepSeek DeepInfer» in titles and canonical https://deepinfer.run to keep search intent clear.
