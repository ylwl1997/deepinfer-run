DeepInfer FAQ

Env vars, eval Pass@1, production-system numbers (attribution required), and OSS gaps — aligned with official README, eval/, and doc/inference_deployment_qa.md.

Attribution — production vs OSS. Figures such as ~155 trillion tokens/day per cluster and ~US$38 per GPU-hour (valley) describe DeepSeek’s production inference system as published in doc/inference_deployment_qa.md and related explainers. They are not what you automatically get after installing open-source DeepInfer. OSS is an offline engine release; KV store, full PD-disagg serving, and DP LB are not included.

DeepInfer vs recipe vs Harness?

  • DeepInfer — offline inference engine for DeepSeek-V4.1-Flash (Apache-2.0).
  • deepseek-recipe — protocols / prompts / tokenization; does not infer.
  • DeepSeek Harness (DSH) — agent runtime · dshbase.com.

What is DSpark?

Draft tokens + confidence-scheduled verification. Enable with DEEPINFER_ENABLE_MTP_VARLEN=1; draft length via DEEPINFER_USE_NEXTN_DECODE (default 5).

SWA Bounded Replay?

Replay a bounded decoder suffix. V4.1 README defaults: compact mode and KEEP_TOKENS=140. Production discussants also describe a 128-token SWA window and bounded replay of about the last 128 tokens — still one engine, two phases.

Why missing KV / PD disagg / DP LB?

OSS focuses on offline inference. A complete service still needs a KV cache system, VE/Prefill/Decode disaggregation service glue, and DP load balancing — listed upstream as not included.

Docker image?

No official Docker image in the README. Any Dockerfile you see on community blogs is a community example only — not an official DeepSeek artifact.
