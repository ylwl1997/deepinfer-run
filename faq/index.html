DeepInfer FAQ

Answers aligned with the official DeepInfer README — offline inference, kernels, and serving gaps.

DeepInfer vs deepseek-recipe vs DeepSeek Harness?

  • DeepInfer — open-source offline inference engine for DeepSeek-V4.1-Flash (Apache-2.0).
  • deepseek-recipe — protocols / prompts / tokenization; does not run inference.
  • DeepSeek Harness (DSH) — agent runtime · dshbase.com · note for DSH readers.

What is DSpark (and speculative decoding)?

DSpark plus confidence-scheduled verification accelerates decoding with draft tokens and schedules verification by confidence. Enable with DEEPINFER_ENABLE_MTP_VARLEN=1; DEEPINFER_USE_NEXTN_DECODE sets max draft length (default 5).

What is SWA Bounded Replay?

Decoder SWA bounded replay reduces decoder prefill work by replaying only a bounded suffix. Default V4.1 settings in the README: DEEPINFER_YOCO_PREFILL_TRUNCATION_MODE=compact and DEEPINFER_YOCO_PREFILL_KEEP_TOKENS=140. The retained suffix must cover the SWA window plus max backtracking length.

Structured outputs?

Constrain generation to a regex, JSON schema, or EBNF via so_args on SamplingParams. See upstream examples/_structured_output.py.

Which kernels power DeepInfer?

Optimized kernels listed upstream: FlashMLA, DeepGEMM, DeepEP, TileKernels, DeepSelect, and custom TileLang ops — plus Attention DP / balanced CP, MoE EP + EPLB.

Batch-invariant and deterministic sampling?

Batch-invariant inference (DEEPINFER_BATCH_INVARIANT=1, NVIDIA only) keeps results identical across batch compositions. Deterministic sampling pairs that flag with DEEPINFER_ENABLE_MTP_VARLEN=0 and a fixed seq_seed.

Why are KV cache, Prefill/Decode disaggregation, and load balancing missing?

The open-source release focuses on offline inference. Upstream explicitly lists what a complete inference service still needs: a KV cache system, VE/Prefill/Decode disaggregation (most engine functionality is implemented; full service glue is not), and load balancing across data-parallel replicas for both prefill and decode. Prefill and Decode remain two phases of the same DeepInfer engine — not separate products.

DeepInfer vs vLLM / SGLang / TensorRT-LLM?

Acknowledgments: DeepInfer was built primarily on vLLM, with inspiration from SGLang and TensorRT-LLM. Use DeepInfer when you want DeepSeek’s V4.1-Flash offline path on SM100 / Ascend 950; see vs vLLM.

Hardware and install?

NVIDIA SM100 (CUDA 13) and Huawei Ascend 950 (CANN 9.2); set DEEPINFER_ACCELERATOR. Guides: hardware, DeepInfer install.

Medical deepinfer.org?

Unrelated. Titles use «DeepSeek DeepInfer»; canonical host is deepinfer.run.
